<size=120%><b>CHAPTER IV | DISPATCH</b></size>

<b>FROM INFORMATION TO ACTION</b>

Once the telegram has been deciphered, its instructions must be transferred to a dispatch punch card.

A standard telegram contains four fields:

DESTINATION: Receiving department
TYPE: Classification of correspondence
HANDLING: Required processing procedure
REFERENCE: Administrative reference designation

<size=110%><b><color=#8B2929>4.1 DISPATCH CARD CONFIGURATION</color></b></size>

Column 1: Destination
Column 2: Mail type
Column 3: Handling
Column 4: Reference

For standard dispatch operations, punch exactly one row per column.
